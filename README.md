# TrackSki

Aplicacion para consultar estaciones de esqui, partes de nieve, meteorologia
y estado de los accesos por carretera.

## Tecnologias

- FastAPI y Python para la API.
- PostgreSQL con PostGIS para datos geograficos.
- Next.js y React con SSR para el frontend.
- Open-Meteo para la ingesta meteorologica actual.
- Docker Compose y Traefik para el despliegue.

La guia completa de desarrollo, endpoints, Docker, despliegue e ingesta se
encuentra en [docu_temp.md](docu_temp.md).
